# Monu Bhabhi Ji — Sorry Website ❤️

A cinematic apology microsite customized for Monu Bhabhi Ji.

## Main message
“I’m really very sorry, Dost… This was the very first and last time I did this. I promise, I’ll never do this again. I’m genuinely sorry for whatever I have done, but you mean a lot to me and you know that very well. Please forgive me, Monu Bhabhi Ji. I love you and I miss you so much.”

## Run locally

1. Install Node.js LTS.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Edit text
- `index.html` contains the visible messages, name, and credits.
- `birthday.css` controls the visual design.
- `birthday.js` controls the animation and interactions.
- `media/` contains the current intro audio/video assets.

## Privacy note
No personal photo/video files have been added to this package yet. When media is added for the final version, use a private storage bucket and signed URLs rather than public file URLs.
